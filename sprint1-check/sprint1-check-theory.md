# rfSE Sprint1 Check Questions for RFSE Club

Below are 40 beginner-friendly questions on fundamental computer science concepts that we have discussed so far.

## Questions

1. Explain in 3 sentences how computers evolved from mechanical to electronic, focusing on key milestones like ENIAC and transistors.

2. Describe 2 advantages of CLI over GUI for beginners, with simple examples like file navigation.

3. Write steps to create, edit, and save a "hello.txt" file in Vim.

4. List 5 basic Linux terminal commands (e.g., ls, cd) and what they do.

5. Why use a version control system? Give 1 real-world example for a solo coder.

6. Explain "git commit" vs "git push" in 2 sentences.

7. How do you create a repository and upload a file on GitHub? Provide step-by-step instructions, no code.

8. Name 2 high-level programming languages and explain why they're easier for beginners.

9. Define compiler vs interpreter, providing 1 example for each.

10. How does a JIT compiler differ from a traditional compiler? Provide a simple explanation.

11. What does a transpiler do? Give an example using Babel for JavaScript.

12. List 3 traits of good software (e.g., efficient, user-friendly).

13. How can you compare two programs' speed and memory usage?

14. Write pseudocode to check if a number is prime.

15. Draw a simple diagram showing how the CPU accesses RAM.

16. Compare strictly typed vs loosely typed languages with an example using Java and Python variable assignment.

17. Declare an integer, float, char, string, and boolean variable in pseudocode.

18. Define kernel, process, thread, and core in one sentence each.

19. List 4 states of a thread (e.g., new, runnable).

20. Explain the difference between concurrency and parallelism, using an example like cooking vs team cooking.

21. Why is 1 character stored as 1 byte? Relate to ASCII storage needs.

22. What is ASCII? Show how "A" is encoded as an example.

23. Why is 1 byte 8 bits instead of 7 bits? Explain the historical reason tied to processing efficiency.

24. Why are functions useful? Provide an example using addition logic.

25. Write pseudocode for calling a sum function.

26. Explain the difference between actual and formal parameters with an example in a greet function.

27. Rank register, cache, RAM, and storage by speed.

28. Why is stack memory fixed and heap memory dynamic? Provide a simple allocation example.

29. What does a pointer store? Give an example with an integer pointer.

30. Write pseudocode for a grading system (A/B/C) using an else-if ladder.

31. When should you use a switch case over if-else? Provide an example with a menu.

32. Write pseudocode using logical operators (&&, ||) for an age eligibility check.

33. Write pseudocode to compare two numbers using relational operators.

34. Write pseudocode to print a 3x3 grid using nested for loops.

35. Write pseudocode to sum numbers from 1 to 10 using a while loop.

36. Write pseudocode for a loop that skips even numbers using continue.

37. Define an array and a simple variable, highlighting the difference.

38. Provide a simple explanation of amortized analysis for array resizing.

39. What does O(n) mean in Big O notation? Give an example with a loop over a list.

40. Provide one example each for O(1), O(n), O(n^2), and O(sqrt n) complexities, without code.
